## 何が変わるか
- 見出し h2.title が「名前｜答え」の本文ページ：区切り（全角｜・タグの外の最後の1つ・v3.20.1）の前＝ページの名前を `.hdr`（ロゴの行）へ移す。
  1行目＝ロゴ｜縦の区切り線（.hdr-psep）｜ページの名前（.hdr-pname）、2行目＝答え（h2.title）。
- 答えは元の HTML のまま（大きさ 27px・折り返し・<br>・文言は不変・縮めない）。2行に折り返す答えは2行のまま。
- ページの名前は kit 既定の `.kicker` をそのまま使う（`<span class="kicker hdr-pname">`＝13px・400・ink-60・letter-spacing .18em・uppercase・serif-en）。v2・若松さん 2026-11-11 15:32「ページの名前は、文字の大きさをほかのスライド実績を共有フォルダから探してください。英語がデフォルトかも？」。実例調査で全デッキがこの値。
- 言語は既定で英語（kit 型見本・旧 OPI 定例）だが、apply は文言を変えない（日本語のまま移す）。英語にするかは案件側で決め、見出しの「名前｜答え」の名前を書き換える。
- 規定の改訂（2026-11-11 若松さん決定・15:43 OK）：V3.2_FORMAT・SLIDE_DESIGN_GUIDELINES §5・ブランドガイドブック β0.7・FIGURES_GUIDE の「ロゴの横にキッカー文字を並べない（2026-10-29）」を改訂。本文ヘッダーは2行。1行目はロゴとページの名前（kit 既定は 13px・グレー・英語大文字）、2行目はページタイトル（大きさは変えない）。メインエリアを広く使うため、ヘッダーの高さは伸ばさない。
- 小さいラベル（.hdr 直後の .kicker / .page-name）があるページは、その要素をそのまま .hdr へ移す（大きさ・色は不変）。
- 名前もラベルも無いページは何もしない。表紙・中扉・dark・divider・data-hpn="off" は対象外。冪等。
- 元の見出しは h2 の data-hpn-orig に残す。section に data-talk-h が無いときは元の見出しの文字で足す（発表 T の2段表示は元どおり）。
  発表（T）で見出しが組み替えられたページ（h2[data-ci-tk-orig]）は1行目の名前を隠す（話題が見出し側に出るため重複させない）。
- 5co ロゴ（svg.corner）：答えが1行になったページで本文の開始が 119px に上がり、要点帯と 11px 重なる（FIXED-OVERLAP）ため、
  ci-hpn のページだけ top 15mm→36px（大きさ・右位置は不変・ページ間でそろえる）。
- 余白・数字の帯（header_motion の CSS/JS はバイト不変）・フッター・表紙・中扉は変えない。

## 使い方（オプトイン）
- Python：`html, n = ci_head.apply_header_pagename(html)`（apply_header_motion の後）
- CLI：`python3 ci_head.py --apply-header-pagename deck.html [-o out.html]`
