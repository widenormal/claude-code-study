# Amazon 用語集（CIスライドの正・2026-09-08 制定）

`COPY_GUIDE.md` ルール6「業界の正式用語を使う」の Amazon 版。
**Amazon 案件のスライド・レポートは、この表の「正式用語」を主語に使う。** 独自の言い換えを作らない。
分かりにくい語は、正式用語を残したまま初出で日常語を括弧で添える（ルール4）。

**広告側の用語は `TERMS_AMAZON_ADS.md`（Amazon Ads 公式ガイドを出典とし、行ごとに出典URLと取得日を持つ）が正。**
本ファイルはカテゴリー・商品の単位／順位・シェア／価格を扱う。表記が食い違う場合は出典のある方を採る。

> 制定の経緯: WELLA OPI「ネイル7カテゴリ統合 ASIN構成分析」（2026-09-07 作成）で、
> カテゴリーを一貫して「棚」と書いていた（22枚中 246箇所）。読み手から
> 「棚数とは？カテゴリー数のこと？」と確認が入り、資料の主語が伝わっていないことが判明した。
> 同じ失敗は WELLA ProHair ULTIME 統合版（2026-09-07）でも起きている
> （「併願」＝造語。Amazon では出品者が同時に2つのカテゴリーを選ぶことはできず、
> 途中で「第2候補」に修正）。**2件続いたため正典化する。**

## 1. カテゴリーと商品の単位（今回の事故の中心）

| 正式用語 | 意味 | 使ってはいけない言い換え |
|---|---|---|
| **カテゴリー** | Amazon の商品分類。商品詳細ページのパンくず（例: ビューティー › ネイル › ネイルデザイン › ジェルポリッシュ）の各階層 | 棚 |
| **ブラウズノード**（browse node） | カテゴリーの内部ID。「どのカテゴリーに登録されているか」を厳密に指すときはこちら | 棚・売り場 |
| **末端カテゴリー**（リーフノード） | パンくずの最下層。売れ筋ランキングの母集団になる | 棚 |
| **親ASIN** | バリエーション（色・サイズ）をまとめる商品詳細ページ1本。「カテゴリーに何本置くか」の単位 | 商品ページ・枚・棚に置く数 |
| **子ASIN** | 親にぶら下がる色・サイズごとのASIN。在庫・広告・売上の実体 | 色・サイズ・バリエーション本数 |
| **バリエーション** | 親子構造そのもの。「バリエーション登録」のように使う | — |
| **SKU** | 出品者が付ける在庫管理単位（セラーセントラル）。**ASIN とは別物**。ベンダー取引では「品番」 | ASIN と混用しない |
| **出品**／**未出品** | そのカテゴリーに商品を出しているか | 参入・未参入 |
| **登録カテゴリー** | その商品が実際に登録されているカテゴリー | 登録棚 |

**数え方**：親ASINは「◯ASIN」または「◯件」。「◯枚」「◯本」は使わない（枚＝紙、本＝子ASINと紛らわしい）。
親と子のどちらを数えているかを必ず明示する（例：「親ASIN 30件／子ASIN 1,594件」）。

## 2. 順位・シェア

| 正式用語 | 意味 | 使ってはいけない言い換え |
|---|---|---|
| **売れ筋ランキング**（BSR / Best Sellers Rank） | カテゴリー内の売れ筋順位。商品詳細ページに表示される。**商品単位** | ランキング（曖昧） |
| **カテゴリー内シェア** | そのカテゴリーの売上に占める比率。金額か数量かを必ず添える（例: カテゴリー内金額シェア） | 棚内比・棚シェア |
| **カテゴリー内順位（ブランド別）** | ブランド単位で売上を合算した順位。BSR（商品単位）とは別物 | 棚1位・棚順位 |
| **到達可能なカテゴリーシェアの上限** | 1ブランドが実際に取れているシェアの実測から置く上限 | 天井 |

| 正式用語 | 意味 | 使ってはいけない言い換え |
|---|---|---|
| **価格帯** | 価格の区分（例: ¥2,000–2,999） | 帯（単独で使わない） |
| **中心価格帯**／**ボリュームゾーン** | そのカテゴリーで売上の大半を占める価格帯 | 主戦場 |
| **平均単価** | 売上 ÷ 販売数量。単価の出し方（実売か希望小売か）を明示する | — |

## 4. 実績・広告

| 正式用語 | 意味 | 使ってはいけない言い換え |
|---|---|---|
| **ベンダーセントラル**／**セラーセントラル** | Amazon の管理画面。どちらの取引形態かで指標が変わるため必ず区別する | Amazon の管理画面（曖昧） |
| **販売実績のあるASIN** | 対象期間に売上が観測されたASIN。観測範囲を必ず添える | 稼働ASIN・稼働率 |
| **季節調整後の月商** | 季節指数で割り戻した月あたり売上 | 定常月 |
| **スポンサープロダクト（SP）／スポンサーブランド（SB）／スポンサーディスプレイ（SD）／Amazon DSP** | 広告種別。略称は初出でフル表記。**公式の正式名称は「スポンサープロダクト広告」のように「広告」まで含む**（`TERMS_AMAZON_ADS.md` 1節） | 広告（種別を書かない） |
| **ACoS**（広告費 ÷ 広告経由売上）／**TACoS**（広告費 ÷ 総売上）／**ROAS**（広告経由売上 ÷ 広告費） | 3つは分母・分子が違う。どれを指すか必ず明示。**Amazon Ads 公式の表記は「広告費売上高比率（ACOS）」**＝大文字（`TERMS_AMAZON_ADS.md` 2節・8節） | 広告効率（曖昧） |
| **NTB（New to Brand・そのブランドを初めて買った顧客）** | 新規顧客指標。**この定義は出典未確認**（Amazon Ads 日本語ガイドに該当ページなし・`TERMS_AMAZON_ADS.md` 7節） | 新規（定義を書かない） |
| **カニバリゼーション（自社内競合）** | 自社商品どうしの需要の食い合い | カニバリ（略さない） |
| **在庫切れ（OOS）** | — | 欠品（社内語。初出で併記なら可） |

## 4b. シェア率を出すときの分母（2026-09-08 追加）

Amazon 案件でカテゴリー内シェアの目標を立てるときは、**分母を対処可能市場に限定する**
（一般則＝`V3.2_FORMAT.md`「シェア目標の分母は『対処可能市場』にする」）。

- **既に出品しているカテゴリー** … カテゴリー全体を分母にしてよい（自社商品が価格帯をまたいで売れているため）
- **未出品のカテゴリー** … 参入する価格帯だけを分母にする。カテゴリー全体で割ると、
  自社の価格では届かない規模まで「余地」に数えてしまう
- **自社の価格がそのカテゴリーに存在しない価格帯のとき** … 分母を作る前に、
  価格・商品設計を見直すか参入しないかの判断が先（ブラウズノードの付け替えでは解決しない）
- 価格帯の分位を使うときは**親ASIN（商品ページ）単位で統一**する。
  子ASIN 単位の金額と親ASIN 単位の件数を混ぜない

## 5. 書くときの手順

1. 書き終えたら、この表の「使ってはいけない言い換え」列を検索する（`棚` `帯` `天井` `主戦場` `稼働` `定常月` `未参入`）。1件でも残っていれば直す
2. 「ASIN」と書いたら、**親か子かが文脈から一意に決まるか**を確認する。決まらなければ「親ASIN」「子ASIN」と書く
3. 略語（BSR・ACoS・TACoS・NTB・SP/SB/SD・DSP・OOS）は初出でフル表記＋日常語（ルール4）
4. 新しい言葉を作りたくなったら、それは**まだ実務用語を調べていない**サイン。作る前に Amazon の公開ヘルプ・セラーセントラルの表記を確認する
5. シェア率を書いたら、**分母が何か**を資料上で明示できているか確認する（4b 節）

## 6. どうしても言い換えが必要なとき

正式用語が無い概念（自社の分析上の造語）は、**造語だと分かるように書く**。
- 資料内で初出時に「本資料では〜と呼ぶ」と定義する
- 定義ページ（出典と定義）に載せる
- 顧客の社内で独り歩きしても誤解が起きない語を選ぶ

例（ULTIME 2026-09-07）: 「併願」→ Amazon 用語ではないと判明したため「第2候補のカテゴリー」に修正し、
「出品者が同時に2つのカテゴリーを選ぶことはできない」旨をページに明記した。
