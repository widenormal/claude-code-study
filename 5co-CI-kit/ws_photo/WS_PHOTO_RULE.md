# 余白の人物写真ルール — WS_PHOTO_RULE（CI kit v3.21.0・2026-11-11 若松さん決定）

ページに大きな余白があるとき、消費者・インフルエンサー・コンサルタントの人物写真を1枚入れる。
**オプトイン**：`ci_head.py --fill-whitespace-photo deck.html -o out.html`（または `ws_photo/ws_photo.py`）を付けたデッキだけ。付けない出力は今までと同じ。

## 1. 余白の判定（描画後にブラウザで測る・表示が変わるたびに測り直す）
- 本文エリア＝見出し・要点（.gist）の下端から、フッター行（集計期間・ダイジェストボタン・版スタック）の上まで。左右はスライドの内側（12列グリッドの幅）。
- 本文エリアを **12列グリッド**（溝 8px）で切り、行は列幅と同じ**正方モジュール**（A4横で約 75px）。下端に揃える。
- 文字（行ごとの実際の文字の範囲）・画像・表・図・色面・罫線から **8px 以内のマスは「埋まり」**。
- 空きマスでできる長方形のうち、人物（幅:高さ≒0.7:1）を一番大きく置けるものを選ぶ。次を**全部**満たすときだけ入れる。
  - **3列以上 × 2行以上**（高さ 150px 以上）
  - その長方形が**本文エリアの 15% 以上**
- 判定は通常表示・ダイジェスト・発表（T）・印刷／#static で**それぞれ**行う（同じページでも表示ごとに入る／入らないが変わる）。

## 2. 写真の選び方（ペルソナ → 商品カテゴリー × 購入層 → 素材）
**2-1 ページごとのペルソナ**（見出し・要点・ページ名の語。当たった数が最多のもの、同数は上が優先。手で決めるなら `<section data-ws-photo="consumer|influencer|consultant">`）
| ページの主題 | ペルソナ |
|---|---|
| SNS・広告（DSP・スポンサー広告）・認知・表示回数・動画 | インフルエンサー |
| 売上・購買・注文・検索・レビュー・顧客 | 消費者 |
| 施策・計画・提案・戦略・進捗・振り返り・OKR・予算・会議 | コンサルタント |

**2-2 デッキの商品カテゴリーと購入層**（若松さん 2026-11-11：消費者とインフルエンサーは商品のカテゴリーと消費者に合わせる。OPI＝ネイルのインフルエンサーと女性の消費者・購入層 `female 20-59`）
- 宣言（優先）：`<html data-ws-category="nail" data-ws-audience="female 20-59">`。カテゴリーは台帳の key（nail・skincare・haircare・bodycare・detergent・petfood…）、購入層は `female|male|any` と年代 `NN-NN`。
- 宣言が無いとき、次の順で決める：ビルダーの指定（`--category`・`--audience`）→ handoff（JSON の category/audience、または「カテゴリー：」「購入層：」の行）→ 本文の語（台帳の各カテゴリーの語が2件以上で最多のもの）→ 購入層はカテゴリーの既定（nail・skincare＝女性。既定が無いカテゴリーは未定）。
- **カテゴリーか購入層が決まらなければ、消費者・インフルエンサーは入れない**（コンサルタントだけ入る）。

**2-3 素材の台帳（`ws_photo/assets.json`）**：素材ごとに persona・gender・age（NN-NN）・categories（`*`＝商品を持たない汎用）・審査の根拠・status（approved／candidate）・**external_ok**（社外版・顧客向けに使ってよいか）と external_basis（その根拠）を持つ。approved だけを使う。
- 消費者＝性別が購入層と同じ・年代が重なる・カテゴリーが一致するもの優先（無ければ `*` の汎用）。
- インフルエンサー＝**カテゴリーが一致するものだけ**（汎用は不可）・性別が合う。
- コンサルタント＝カテゴリー・購入層に関係なく従来どおり（素材は `facing_marketer_03_v5`。kit 上の名前は marketer）。
- 合う素材が無いペルソナのページには入れない（状態に「素材なし」と理由を出す）。ピッカーにも、このデッキに合う素材だけを出す。
- 人物写真は **審査済みの既存素材だけ**（衣装・フォト両ディレクター合格）。新しく生成しない（生成は金曜午前 JST のみ）。表情・衣装に疑いがあるものは candidate のまま使わない。
- 素材は kit に入れない（FIGURES_GUIDE §2-2）。台帳に場所と審査の根拠を書き、出力に WebP（長辺 1600px 以下・既定 800px）で埋め込む。

**2-4 キャプションと alt**：キャプション＝ペルソナ名（デッキ内の表記に合わせる。例「Amazonユーザー」「ネイルのインフルエンサー」「コンサルタント」）。alt＝「ペルソナ名（架空の人物）」、切り抜きは「ペルソナ名（架空の人物・背景なし切り抜き）」（COPY_GUIDE ルール10・11）。「イメージ」とは書かない。

## 3. 置き方
- グリッドの区画に合わせる。人物の幅に合わせて列数を詰め（最低3列）、**区画の右寄せ・下揃え**。
- 形は「Amazon人物型」と同じ：**#C3D7EE の角丸面（上 34% から下）に切り抜き人物**。頭は面の上に出てよい。人物は無加工・下端フェード禁止・手前に水色を重ねない。
- キャプションは写真の下 16px（10px・右寄せ）。
- **文字には重ねない**：写真の横の見出し・箇条書きは、行の右が空いているときだけ箱の幅を写真の手前で止める（文字は動かさない）。折り返しが変わるなら入れない。
- **1ページ1枚**：同じページにほかの人物写真（.dg-photo・.dgx-person・ピッカーで置いた写真）が見えていれば入れない。

## 4. 入れない場合
- 表紙・中扉・SERP の根拠ページ。
- 通常表示で**表が見えているページ**（表・数字が主役）。ダイジェストで表が隠れれば判定する。
- 空きが 1. の条件に満たない。
- **社外版で、合う素材に external_ok が無い**とき。権利は**素材ごと**に台帳の external_ok で決める（デッキ単位の `--rights-confirmed` は v3.21.0 で廃止。付けても無視して注意を出す）。
  - `ci_head.py --fill-whitespace-photo … --external`：external_ok の素材だけで選ぶ。
  - `fp_build.py external`：社内版の余白写真をいったん外し、`--ws-photo` を付けたときだけ external_ok の素材で入れ直す。
  - external_ok＝true は根拠（指示・審査の記録）を external_basis に書いたものだけ。2026-11-11 時点：INF-02 紫苑ミラ（ネイル）＝true（若松さん「顧客むけでも問題ありません」）、consumer_01_headroom（Amazonユーザー）・facing_marketer_03_v5（コンサルタント）＝true（同日の追加指示「紫苑ミラと同じく顧客向けOK」）。ほかは false（未確認）。
- `data-ws-photo-skip="理由"` を付けたページ。一覧表示（O）。

## 5. Framework ピッカー：ダイジェストの図を写真に置き換える（社内版だけ）
- ダイジェスト表示の図（例 p06 の「P+ のROAS（8月→9月）」）の Framework 一覧の先頭に
  「**人物写真（消費者・インフルエンサー・コンサルタント）**」と「**任意の写真（ファイルから選ぶ）**」。
- 人物写真は 2. と同じ審査済み素材から選ぶ。任意の写真はファイルを WebP・長辺 1600px 以下に縮めて使う。
- 写真は**図の枠いっぱい**。高さはグリッドの行（正方モジュール）に揃え、最低2行。本文エリアからはみ出すなら1行ずつ下げる。
- 「元に戻す」で元の図と枠の大きさに戻る。「修正を反映した版を書き出す」にも入る。社外版（fp_build.py external）には入らない。
- ピッカーは**単一選択**（1つの図に Framework か写真のどちらか1つ。同じものをもう一度押すと元の図）。バーに「保存」は置かず、JSON はダウンロードしない（その場で自動保存・反映は「修正を反映した版を書き出す」だけ）。
- 写真に置き換えると、その図の数字（例 8月209%→9月178% の棒）はダイジェストから消える。要点（.gist）に同じ数字があるページで使う。

## 決定事項（2026-11-11 若松さん）
1. 閾値＝本文エリアの 15% 以上・3列×2行以上（高さ 150px 以上）。
2. 宣言の属性名＝`data-ws-category`／`data-ws-audience`。既定の購入層＝nail・skincare は女性。
3. OPI の購入層＝`female 20-59`。
4. コンサルタントの素材＝`facing_marketer_03_v5`（キャプション「コンサルタント」・alt「コンサルタント（架空の人物）」）。
5. INF-02 紫苑ミラ・consumer_01_headroom（Amazonユーザー）・facing_marketer_03_v5（コンサルタント）＝顧客向け・社外版でも使ってよい（external_ok＝true）。**ピッカー自体は社内版だけ**のまま。
