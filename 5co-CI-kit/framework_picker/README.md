# framework_picker — 図の型（フレームワーク）ピッカー（試作 2026-11-11・CIスライド）

社内で開いたときだけ、各図の下端の高さ（スライドの右余白）に「型▾」ボタンが出る。押すと SLIDE-PATTERN 129種
（修正依頼欄と同じ ID・`frameworks_catalog.json`）のうち、**このページの数字（表の値）で描ける型だけ**を出す。
**1つの図に Framework は1つ（単一選択・v3.21.0・2026-11-11 若松さん指摘）**：押すとその型に切り替え、別の型を押すと置き換え、
同じ型をもう一度押すと元の図に戻る。「複数」「件数」の表示とボタンのバッジの件数は出さない。
数字で描けない型（見本の絵だけの型）は、おすすめにも「ほかの型を見る」にも出さない（描ける型が無い図は「このページの数字で描ける型がありません」）。
表の値は「630万」「1,989万」「¥114」「▲542万」「101.2%」なども読む。行が多い表（シリーズ別・日別）は行を横軸にして描き、「計」「合計」の行は描かない。
**OKR は必ず使う Framework（v3.21.1・若松さん指示）**：目標と実績がページにあればおすすめの先頭に出す（どちらかが無ければ出さない）。上段 Objective（目標＝適正/必達、実績＝対必達・対適正・YoY・○△×）→ シリーズ別カード（商品画像・目標・実績＋達成率＋YoY＋○×、広告費、広告経由売上＋ROAS、達成率推移）→ 下段 KR・考察帯を、そのページの実データだけで描く（無い値は作らない）。サムネは模式図（数字・文字なし）、表示名は「OKR」（英語 ID は出さない）。社外版の書き出しでは除去する。

## 社内での使い方
```bash
K=<共有フォルダの 5co-CI-kit>          # claude.md を置いたフォルダから見える kit
python3 $K/framework_picker/fp_build.py internal deck.html -o deck_社内版.html [--base-dir 元デッキのフォルダ]
```
- 出来た `deck_社内版.html` を Chrome で開く → 各図の右下の余白に「型▾」。Shift+P か右下のバーで「提出プレビュー」と「編集モード」を切り替える（v3.21.1・2026-11-11 19:20 若松さん指示）。ピッカーとテキスト修正の操作が出ているときのボタンは「提出プレビュー」（旧「表示中」）。押すと操作が隠れ、提出時の見た目になり、ボタンは「編集モード」（旧「非表示」）になる。title と aria-label も同じ文言。
- 選んだ型・文言の修正・写真の置き換えは localStorage にその場で自動保存（同じファイル名なら次に開いても残る）。
  **バーに「保存」ボタンは置かず、JSON のダウンロードもしない**（v3.21.0・2026-11-11 若松さん指摘＝コードに慣れていない社員に分からないため）。
  反映は右下のバーの「修正を反映した版を書き出す」だけ（HTML 1ファイル）。
- 型の一覧は書き出しのときに kit から読み込む＝共有フォルダの kit を見ている社員は全員同じ一覧。
  出来た HTML は1ファイルで動く（ドライブを参照しない）。
- `#static`・印刷・PDF・検査ではピッカーを出さない（最終状態＝社外版と同じ見た目）。

## 文言の修正（社内版だけ）
- 本文の文字を選ぶ（1つの文字のまとまりの中だけ。太字などをまたぐ選択は不可）→「修正」→ 書き換えて「修正する」。
  画面では元の文に取り消し線・新しい文に下線で差分を出す。押すと取り消し。
  **提出プレビュー（`html.ci-fp-hidden`）と `#static`・印刷では、この印をすべて消し、新しい文だけを通常の本文と同じ見た目で出す**（編集前の文には戻さない）。編集モードでは従来の印を出す。右下バーの「修正を反映した版を書き出す」と `fp_build.py external` は印のクラス・スタイルを残さず、新しい文だけにする（v3.21.1・若松さん指示 19:37）。
- 修正は {slide, sel（要素の目安）, tag, node_text（元の文の段）, node_k, offset, old, new, time, numbers} として
  localStorage に自動保存する（JSON のダウンロードはしない。反映は「修正を反映した版を書き出す」）。
- 数字を含む修正は「要確認（内容担当の確認待ち）」として琥珀で目立たせ、JSON に numbers=true・status を付ける。
- 正本への反映（元のデッキに当てる・社内版には当てない）:
```bash
python3 $K/framework_picker/fp_apply_edits.py deck.html deck.fp-selections.json -o deck_修正後.html [--dry-run] [--allow-numbers] [--only e1,e2]
```
  JSON の箇所だけを、位置の文字が元の文と一致するのを確かめて置換する（一括リライトはしない）。数字を含む修正は
  --allow-numbers が無ければ適用しない（HOLD）。全部の表の行数・セル数・ヘッダー最終列・1列目の並びを前後で照合し、
  修正で説明できない差が出たら中止（書かない）。出力は必ず別名。

## Framework の確定・挿入と修正を反映した版（v3.20.0・社内版のみ）
- Framework チップとテキスト修正はスライドの右外の列に出る。おすすめはサムネイルで選び、そのページの数字だけで描き替える（無い値は描かない）。
- プレビューは元の図のグリッド枠の実寸でその場に描く。「この型で確定」・画像/表の挿入ができる。
- 修正を反映した版：`python3 $K/framework_picker/fp_export_applied.py deck_社内版.html state.json -o deck_修正反映.html [--confirm-only] [--allow-numbers]`
  （数字を含むテキスト修正は既定で当てない・表の前後照合が合わなければ書かない・出力は別名）。社外版には編集機能を入れない。

## 社外に出すとき
```bash
python3 $K/framework_picker/fp_build.py external deck_社内版.html -o deck_社外版.html \
        [--figs figs_redraw/] [--selections deck.fp-selections.json] [--base-dir 元デッキのフォルダ]
bash $K/ci-gates.sh --external deck_社外版.html
```
- ピッカーの DOM・CSS・JS・型の一覧・`data-fp-*`・選択メモを全部外し、相対パスの画像は data: に埋め込む。
- **埋め込み画像の軽量化（v3.21.1・社外版だけ）**：写真（透過の無い PNG／JPEG）は WebP 品質 85・長辺 1600px 以下にする。ロゴや透過が必要な切り抜きは透過 WebP（小さなロゴは可逆を優先して見た目を崩さない）。SVG はそのまま。このデッキの要素に当てはまらない CSS の kit 背景（数字背景のライトバリアントなど、使っていないもの）は除外する。社内版は今までどおり埋め込んだまま。**Pillow が import できないときは WebP 化を飛ばして警告を出し、書き出しは成功する**（未使用背景の除外は Pillow なしでも行う）。
- `--figs` に `<図ID>.html`（例 `p03-2.html`）＝**元デッキのデータから** ci_frameworks.py などで描き直した断片を
  置くと、その図と差し替えて埋め込む（断片の `<script>`・コメントは落とす）。無い図は元の図のまま。
- 書き出しの最後に `fp_external_check.py` を走らせ、痕跡が1つでも残れば書き出さない。上書きもしない。

## 検品（fp_external_check.py・ci-gates.sh「社外版の痕跡」）
- `--external` を付けたとき：picker（ci-fp-・data-fp-・CIFP…・文言修正の ci-te-・data-te=・data-old=）／path（file:・/workspace/・/Users/・共有ドライブ・
  マイドライブ・CloudStorage・drive.google.com・CLAUDE.md…）／ref（src・href・url() の相対パス）を FP_TRACE で落とす。
- v3.19.0：vendor＝仕入れ元の名前（`VENDOR_NAMES`＝Ignite・DMT・大文字小文字を区別しない）も FP_TRACE vendor で落とす
  （契約上の必須）。社外版の出どころ注記・型の一覧の社外向け文言に仕入れ元の名前を書かない。名前を置いてよいのは社内のコード・テスト・
  この禁止語の一覧だけ。英数字の途中（埋め込み画像の base64 など）は数えない。Shelpha は禁止語に入れない（v3.19.2）＝
  社外版も ci_head の既定どおりフッターに「CI · Shelpha · Template」の版を出す（若松さん決定 2026-11-03・v3.14.2）。
- 付けないとき：ピッカー入りの社内版に FP_INTERNAL?（社外に出さない）を警告で出すだけ。

## 守ること
- 型見本は模式図で数値を持たない。数字の入った図は元デッキのデータだけで描き直す（作らない）。
- 社外版に Shelpha の名前・推計の手法・データの出どころを足さない（ピッカーは何も足さない）。
- `frameworks_catalog.json` は `make_catalog.py` で作り直す（元＝corporate-website の slide-patterns.ts）。

## ダイジェストの図を写真に置き換える（v3.20.2 試作・社内版のみ）
- `fp_build.py internal deck.html -o deck_社内版.html --photos ws_photo/assets.json`（審査済みの人物写真を同梱。無ければ人物写真は押せない）
- ダイジェスト表示の図（.dgx-cmp＝図ID `pNN-dgN`。既存の図の番号は変えない）の一覧の先頭に「人物写真（消費者・インフルエンサー・コンサルタント）」「任意の写真（ファイルから選ぶ）」。
- 写真は図の枠いっぱい・高さはグリッドの行に揃える。「元に戻す」で元の図に戻る。「修正を反映した版を書き出す」に入る。社外版には入らない（余白の人物写真 ws_photo も external で外す）。規定＝ws_photo/WS_PHOTO_RULE.md §5
