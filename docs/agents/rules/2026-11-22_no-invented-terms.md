- 事例：Shelphaのoffer_typeを説明するときに「Amazon直販／出品者販売」という言葉を作り、公式で確かめないまま表にした。Amazonの公式の表示は「販売元」「出荷元」。

## 決まり
1. 用語を自分で作らない。言い換えや通称（例：Amazon直販、1P/3P）を、公式の用語のように使わない。
2. わからない用語や自信のない用語は、使う前に必ずその会社・サービスの公式ドメイン（例：amazon.co.jp、sell.amazon.co.jp、各社の公式ヘルプ）で確かめ、出どころのリンクを付ける。
3. 公式で確かめられないときは、その言葉を使わずに中身を説明するか、「公式では確認できなかった」と書く。
4. 取り次ぎ先のLLM（claude -p / codex exec / agy / muse など）への指示文にも、この決まりを書く。LLMが出した用語も、提出前に同じように確かめる。
5. 社内で決まった用語（例：GMV、Handoff Mode）は、正本のmdにあるとおりに使う。
