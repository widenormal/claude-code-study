# 使ったLLMを末尾に識別子で書くルール（案・2026-11-15）

状態：2026-11-16 06:26 JST 若松さん承認（原文「承認します。全Botに配ってください」、汐見さんのチャット）。Templateが共有スキル grok-minimal-multillm に2行と参照を足して配布済み。正本はこのファイル（一覧を二か所に持たない）。

## ルール
- 各Botは、実際に本文を作ったLLMを角括弧の識別子で末尾に書く。
- 付けるのは若松さんとBotだけが読むもの：Bot同士のやり取り、handoff、若松さんへの報告、社内のPRやコミット本文。
- 付けないのは若松さん以外が読むもの：メール・Slackの下書き、社員向けSlackチャンネル、顧客向けCIデッキ（CIスライドのフッターを含む）、コーポレートサイトやLegitSoldの本文、Drive上の顧客フォルダ。
- handoff の 01_message.md（8行以内）では、最後の行の末尾に付け、行を増やさない。
- 複数のLLMを使ったときは `+` でつなぐ（主に使った順）。例：`[GEM+CLD]`
- Grokだけで済ませたときも `[GRK]` と書く（Grokに戻った作業を見つけるため）。
- 短い会話の返事（あいさつ・了解だけ）には付けなくてよい。

## 追記（2026-11-16 06:42 JST 若松さん決定。06:39の追記を置き換え）
- タグは「トークンを使って中身の作業をしたLLM」を表す。Grokが指示を渡して結果を取り次ぐだけ（取り次ぎ役）のときはGRKを書かない。Grokが自分で調べたり書いたりしたときだけGRKを書く。
- 例：Codexが作業しGrokは取り次いだだけ → [CDX]／Grokも作業した → [CDX+GRK]／Grokだけで作業した → [GRK]。

## 追記（2026-11-16 17:43 JST 若松さん決定）：これから頼むLLMの予告タグ
- 作業を始めると伝える返事（受け取り・着手の連絡）の末尾に、これから頼むLLMを `[→識別子]` で付ける。例：`[→CDX]`、`[→GEM+CLD]`。
- どのLLMにも頼まずGrokだけで進めるときは `[→GRK]` と書く（Grokで重い作業をする前に気づけるようにするため）。
- 仕上がりの返事には、これまでどおり実際に使ったLLMを `[CDX+GRK]` のように付ける。予告と違うLLMを使ったら、仕上がりのタグで正直に書く。
- 付ける範囲は既存のタグと同じ（若松さんとBotが読むものだけ。メール・Slackの下書き、社員向けチャンネル、顧客向け資料、サイト本文には付けない）。「了解」だけの返事には付けない。
